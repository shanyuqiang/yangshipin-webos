# Product context

Build an unofficial, standalone LG webOS client for the functionality of https://www.yangshipin.cn/tv/home, inspired by https://github.com/asdf17128/bili-webos.

The user wants reliable live CCTV and satellite channels with TV remote navigation, without finding public playlists or keeping a computer/server running. Full target-page functionality remains the product goal; supported features must be established from the current site and actual-device experiments.

Target: LG CX (webOS 5), Chromium 68 frontend, Node 8 service. Do not change TV region, existing apps, router or proxy settings.



Repository creation does not establish playback feasibility. The current official player, login/session requirements, stream protection and TV compatibility still need verification. No promise of access beyond the user's account or upstream permissions.
