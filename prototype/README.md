# 官方页面兼容性探针

这是独立实验应用，不是已完成的央视频客户端。应用 ID 为 `com.shanyuqiang.yangshipin.prototype`，不会覆盖其他应用。

进入后可用方向键、确定键和返回键操作。点击打开按钮后，应用顶层跳转到官方 HTTPS 页面，不嵌入 iframe，不提取或内置鉴权数据，不修改网络或电视设置。

跳转会卸载探针，因此官网页面内的焦点、返回键、网络错误展示由官网/平台控制；这正是待实机记录的兼容性边界。若无响应，按电视主页键离开，再启动实验。探针不能检测跳转完成后的网络失败，也不把网页打开视为播放成功。

## 检查

在仓库根目录执行 `npm test`。测试使用 Node 内置运行器，覆盖启动焦点、方向键、确定键、返回键、点击和同步导航失败。它们不证明网页播放或电视兼容。

打包：`npm exec --yes --package=@webos-tools/cli@3.2.6 -- ares-package prototype -o dist`（先创建 dist）。设备部署由上层开发流程执行。

官网可能根据 WebOS User-Agent 跳转移动版，须记录最终网址；该结果不能当作原 TV 页已兼容。

验收需记录：电视浏览器版本、最终网址、页面异常、视频 currentTime 持续推进、readyState、退出后再次进入，以及官网网络错误的实际行为。
